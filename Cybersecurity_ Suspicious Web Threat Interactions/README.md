# Cybersecurity: Suspicious Web Threat Interactions

## Overview
This project detects and classifies suspicious web traffic using anomaly detection and machine learning models. It analyzes real traffic logs from AWS CloudWatch.

## Key Features
- EDA & Visual Reports
- Isolation Forest (Anomaly Detection)
- Random Forest & Neural Network Classifiers
- SHAP-based Model Explainability
- Threat Intelligence Insights

## Tech Stack
Python, Pandas, Scikit-learn, TensorFlow, Seaborn, Matplotlib, SHAP

## How to Run
1. Clone the repo
2. Install requirements
3. Open `cybersecurity_web_threat_analysis.ipynb` in VS Code
